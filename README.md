# Enrutados · datos de peajes

Tarifas oficiales de peaje de España (Mitma) en JSON, para que la app
Enrutados se actualice sin publicar una versión nueva.

- `tolls/es_2026.json` — tarifas vigentes desde 2026-01-01.
- Generado con `tools/tolls/build_tolls.py` del repositorio de la app.

URL que consulta la app:
`https://raw.githubusercontent.com/xunevega/enrutados-data/main/tolls/es_2026.json`
